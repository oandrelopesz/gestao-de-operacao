## Contratos compartilhados

- `chaveTermo(s)` = `String(s ?? "").normalize("NFD").replace(/\p{M}/gu, "").toLowerCase().replace(/[^\p{L}\p{N}]+/gu, " ").trim()` (igual no worker e no app).
- Token = `{ t: string, s: number, e: number }` (texto, início e fim em segundos, 2 casas).
- Segmento com tokens = `{ start, end, text, tokens: Token[], ...resto }`; `text` sempre igual a `tokens.map(x => x.t).join(" ")` depois de alinhar.
- Regra de troca (worker `aplicarCorrecoes` e app `aplicarCorrecaoNasMarcas`, mesma lógica): para cada par `{de, para}` (pares com mais palavras em `de` primeiro; par com `chaveTermo(de)` vazia é ignorado), procura a partir de cada token i a menor sequência i..j (sem passar do segmento/parágrafo) cujas chaves não vazias unidas por espaço sejam iguais a `chaveTermo(de)`. Troca por UM token: texto = pontuação inicial do token i + `para` + pontuação final do token j (pontuação = `/^[^\p{L}\p{N}]+/u` e `/[^\p{L}\p{N}]+$/u`); se `para` começa com letra minúscula e o token i começa (depois da pontuação) com maiúscula, a primeira letra de `para` vira maiúscula; `s` do token i, `e` do token j. Se o texto novo é igual ao texto original unido por espaço, não conta como troca. Depois de trocar, continua a busca depois do token novo.
- Marcas = `{ v: 1, p: [string, number, number][][] }` (parágrafos de palavras `[texto, início, fim]`). `textoDeMarcas(m)` = `m.p.map(par => par.map(w => w[0]).join(" ")).join("\n\n")`.
- Tabela `transcritor_termos(id uuid, chave text unique, de text, para text, origem 'manual'|'ia', vezes int, created_at, updated_at)`; RPC `registrar_termos(itens jsonb)` com itens `{chave, de, para, origem}`.
- Áudio: `audios/<id>.m4a` na pasta do orquestrador; URL `https://transcritor.minuanoai.com.br/audio/<id>.m4a`.

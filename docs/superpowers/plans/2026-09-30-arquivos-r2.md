# Arquivos no Cloudflare R2 — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Arquivos, Notas e Fluxogramas passam a guardar arquivos no Cloudflare R2 (bucket privado `gestao-arquivos`), com leitura de reserva no Storage do Supabase por 30 dias e migração dos arquivos existentes, sem nenhuma funcionalidade parar.

**Architecture:** Uma edge function `r2` guarda as chaves e assina URLs S3 (`aws4fetch`); o navegador envia e baixa direto do R2 por essas URLs. Regras puras em `src/lib/r2Chaves.ts` (testadas com `node --test`), I/O em `src/lib/r2.ts`, e os três módulos trocam `supabase.storage` por essas funções. O caminho de cada arquivo continua o mesmo (com o módulo na frente, no R2), então o banco não muda.

**Tech Stack:** TanStack Start + React 19 + TypeScript, Supabase JS (Lovable Cloud), Deno (edge functions), Cloudflare R2 (API S3), `aws4fetch` por URL (`https://esm.sh/aws4fetch@1.0.20`).

**Spec:** `docs/superpowers/specs/2026-09-30-arquivos-r2-design.md`

```ts
// Arquivos do sistema no Cloudflare R2 (spec 2026-09-30-arquivos-r2-design.md): regras puras, sem imports.
// Rodam no navegador e no `node --test`. A edge function `r2` repete a validação de chave, porque é
// publicada sozinha e não importa código do app.

/** Módulo do sistema → bucket onde os arquivos dele ficavam no Storage do Supabase. */
export const MODULOS_R2 = { arquivos: "pdfs", notas: "notas", fluxogramas: "fluxogramas" } as const;
export type ModuloR2 = keyof typeof MODULOS_R2;

const TAMANHO_MAX_CHAVE = 512;

/** Caminho dentro do módulo: sem barra no início, sem "//", sem "." ou "..", sem barra invertida e sem caractere de controle. */
export function caminhoValido(caminho: string): boolean {
  if (!caminho || caminho.startsWith("/") || caminho.includes("//") || caminho.includes("\\")) return false;
  if (caminho.split("/").some((parte) => parte === ".." || parte === ".")) return false;
  for (const ch of caminho) {
    const codigo = ch.charCodeAt(0);
    if (codigo < 32 || codigo === 127) return false;
  }
  return true;
}

/** Chave do objeto no R2: `<modulo>/<caminho>` (o caminho é o mesmo que o arquivo tinha no Supabase). */
export function chaveR2(modulo: ModuloR2, caminho: string): string {
  if (!Object.prototype.hasOwnProperty.call(MODULOS_R2, modulo)) throw new Error(`Módulo inválido: ${String(modulo)}`);
  if (!caminhoValido(caminho)) throw new Error(`Caminho de arquivo inválido: ${caminho}`);
  const chave = `${modulo}/${caminho}`;
  if (chave.length > TAMANHO_MAX_CHAVE) throw new Error("Caminho de arquivo longo demais.");
  return chave;
}

/** Endereço fixo de uma imagem de nota: a função `r2` redireciona para um link assinado novo a cada acesso. */
export function urlImagemNota(supabaseUrl: string, arquivo: string): string {
  return `${supabaseUrl.replace(/\/+$/, "")}/functions/v1/r2?c=${encodeURIComponent(chaveR2("notas", arquivo))}`;
}

/**
 * Nome do arquivo de uma imagem de nota que é nossa, no endereço antigo (Storage público do Supabase) ou no novo
 * (função `r2`). Imagem de fora (colada de um site) devolve null.
 */
export function arquivoDaImagemNota(src: string): string | null {
  const antigo = /\/storage\/v1\/object\/public\/notas\/([^?#]+)/.exec(src);
  const novo = antigo ? null : /\/functions\/v1\/r2\?(?:[^#]*&)?c=([^&#]+)/.exec(src);
  if (antigo) return validado(decodificar(antigo[1]));
  if (!novo) return null;
  const chave = decodificar(novo[1]);
  return chave && chave.startsWith("notas/") ? validado(chave.slice("notas/".length)) : null;
}

/** decodeURIComponent que não lança: sequência "%" malformada (endereço colado de qualquer lugar) devolve null. */
function decodificar(s: string): string | null {
  try {
    return decodeURIComponent(s);
  } catch {
    return null;
  }
}

const validado = (arquivo: string | null): string | null => (arquivo && caminhoValido(arquivo) ? arquivo : null);
```

**Files:**
- Create: `supabase/functions/r2/index.ts`

**Interfaces:**
- Produces (HTTP, `https://<projeto>.supabase.co/functions/v1/r2`):
  - `GET` → `{ r2: boolean, bucket: "ok" | string }` (status: secrets presentes e bucket respondendo); `GET ?c=notas/<arquivo>` → 302 para URL assinada
  - `POST { acao: "enviar", chave }` → `{ url }`; `"ler"` → `{ url }` ou 404; `"apagar", chaves` → `{ apagados }`; `"copiar", de, para` → `{ ok }` ou 404; `"listar", prefixo` → `{ chaves }`
  - `POST { acao: "migrar", modulo, direcao: "para-r2" | "para-supabase", limite }` → `{ copiados, erros, existentes, faltam, total, invalidos }` (um arquivo com erro não trava os outros; `erros` = `[{ caminho, motivo }]`; para em ~100 s); `POST { acao: "conferir", modulo }` → `{ iguais, soNoSupabase, soNoR2, tamanhoDiferente }` (as duas exigem `x-swipe-key`)
  - Erros: `{ error }` com 4xx/5xx. POST exige `apikey` = chave pública do projeto.

Sem teste automatizado (só I/O). A verificação é o roteiro da Task 7.

```ts
// Arquivos do sistema no Cloudflare R2 (spec docs/superpowers/specs/2026-09-30-arquivos-r2-design.md).
//   GET                                   -> { r2, bucket }                  secrets configurados e bucket respondendo?
//   GET ?c=notas/<arquivo>                -> 302 para URL assinada           endereço fixo das imagens das notas
//   POST { acao: "enviar", chave }        -> { url }                         URL assinada de PUT (15 min)
//   POST { acao: "ler", chave }           -> { url } | 404                   URL assinada de GET (1 h)
//   POST { acao: "apagar", chaves }       -> { apagados }
//   POST { acao: "copiar", de, para }     -> { ok } | 404 | 400 (módulos diferentes)
//   POST { acao: "listar", prefixo }      -> { chaves }
//   POST { acao: "migrar", modulo, direcao, limite } -> { copiados, erros, existentes, faltam, total, invalidos }  (x-swipe-key)
//   POST { acao: "conferir", modulo }     -> { iguais, soNoSupabase, soNoR2, tamanhoDiferente }         (x-swipe-key)
// POST exige o cabeçalho apikey com a chave pública do projeto: o mesmo nível de acesso que o Storage tinha.
// deno-lint-ignore-file no-explicit-any
import { AwsClient } from "https://esm.sh/aws4fetch@1.0.20";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2.21.0";

const cors = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type, x-swipe-key",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
};

class ErroHttp extends Error {
  constructor(public status: number, mensagem: string) {
    super(mensagem);
  }
}

function json(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), { status, headers: { ...cors, "Content-Type": "application/json" } });
}

const env = (k: string) => Deno.env.get(k) || "";

// ------------------------------------------------------------------ chaves

/** Módulo do sistema → bucket onde os arquivos dele ficavam no Supabase (igual a src/lib/r2Chaves.ts). */
const MODULOS: Record<string, string> = { arquivos: "pdfs", notas: "notas", fluxogramas: "fluxogramas" };

/** Mesma regra de src/lib/r2Chaves.ts (esta função é publicada sozinha e não importa código do app). */
function chaveValida(chave: unknown): chave is string {
  if (typeof chave !== "string" || chave.length > 512) return false;
  const barra = chave.indexOf("/");
  if (barra < 1 || !Object.prototype.hasOwnProperty.call(MODULOS, chave.slice(0, barra))) return false;
  const caminho = chave.slice(barra + 1);
  if (!caminho || caminho.startsWith("/") || caminho.includes("//") || caminho.includes("\\")) return false;
  if (caminho.split("/").some((parte) => parte === ".." || parte === ".")) return false;
  for (const ch of caminho) {
    const codigo = ch.charCodeAt(0);
    if (codigo < 32 || codigo === 127) return false;
  }
  try {
    encodeURIComponent(caminho); // surrogate solto: não vira URL
  } catch {
    return false;
  }
  return true;
}

function exigirChave(chave: unknown): string {
  if (!chaveValida(chave)) throw new ErroHttp(400, "Chave de arquivo inválida.");
  return chave;
}

/** Prefixo de listagem: `<modulo>/` ou `<modulo>/<pasta>/`. */
function exigirPrefixo(prefixo: unknown): string {
  if (typeof prefixo !== "string" || !prefixo.endsWith("/")) throw new ErroHttp(400, "Prefixo inválido.");
  const semBarra = prefixo.slice(0, -1);
  if (!Object.prototype.hasOwnProperty.call(MODULOS, semBarra) && !chaveValida(semBarra)) throw new ErroHttp(400, "Prefixo inválido.");
  return prefixo;
}

function exigirModulo(modulo: unknown): string {
  if (typeof modulo !== "string" || !Object.prototype.hasOwnProperty.call(MODULOS, modulo)) throw new ErroHttp(400, "Módulo inválido.");
  return modulo;
}

// ------------------------------------------------------------------ acesso

/** Chave pública do projeto (a mesma que o app usa): a do ambiente ou um JWT anon deste projeto. */
function chavePublicaValida(apikey: string): boolean {
  if (!apikey) return false;
  if (env("SUPABASE_ANON_KEY") && apikey === env("SUPABASE_ANON_KEY")) return true;
  try {
    const ref = new URL(env("SUPABASE_URL")).hostname.split(".")[0];
    const carga = JSON.parse(atob(apikey.split(".")[1].replace(/-/g, "+").replace(/_/g, "/")));
    return carga.role === "anon" && carga.ref === ref;
  } catch {
    return false;
  }
}

function iguais(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let d = 0;
  for (let i = 0; i < a.length; i++) d |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return d === 0;
}

function exigirChaveDoSwipe(req: Request): void {
  const chave = env("SWIPE_KEY");
  const enviada = req.headers.get("x-swipe-key") || "";
  if (!chave || !enviada || !iguais(enviada, chave)) throw new ErroHttp(403, "Esta ação exige a chave do swipe (x-swipe-key).");
}

// ------------------------------------------------------------------ R2 (API S3)

const SECRETS_R2 = ["R2_ACCOUNT_ID", "R2_ACCESS_KEY_ID", "R2_SECRET_ACCESS_KEY", "R2_BUCKET_ARQUIVOS"];
const r2Configurado = () => SECRETS_R2.every((k) => !!env(k));

function r2() {
  const faltam = SECRETS_R2.filter((k) => !env(k));
  if (faltam.length) throw new ErroHttp(503, `Faltam secrets do R2: ${faltam.join(", ")}.`);
  return {
    // retries: 3 (o padrão do aws4fetch é 10, com espera crescente: estouraria o tempo da função)
    aws: new AwsClient({ accessKeyId: env("R2_ACCESS_KEY_ID"), secretAccessKey: env("R2_SECRET_ACCESS_KEY"), service: "s3", region: "auto", retries: 3 }),
    base: `https://${env("R2_ACCOUNT_ID")}.r2.cloudflarestorage.com/${env("R2_BUCKET_ARQUIVOS")}`,
  };
}

const codificar = (chave: string) => chave.split("/").map(encodeURIComponent).join("/");

async function assinar(metodo: "GET" | "PUT", chave: string, segundos: number): Promise<string> {
  const { aws, base } = r2();
  const url = new URL(`${base}/${codificar(chave)}`);
  url.searchParams.set("X-Amz-Expires", String(segundos));
  const assinado = await aws.sign(url.toString(), { method: metodo, aws: { signQuery: true } });
  return assinado.url;
}

async function existe(chave: string): Promise<boolean> {
  const { aws, base } = r2();
  const r = await aws.fetch(`${base}/${codificar(chave)}`, { method: "HEAD" });
  if (r.status === 404) return false;
  if (!r.ok) throw new ErroHttp(502, `R2 respondeu ${r.status} ao conferir o arquivo.`);
  return true;
}

async function apagar(chaves: string[]): Promise<number> {
  const { aws, base } = r2();
  let apagados = 0;
  for (let i = 0; i < chaves.length; i += 10) {
    const lote = chaves.slice(i, i + 10);
    const respostas = await Promise.all(lote.map((c) => aws.fetch(`${base}/${codificar(c)}`, { method: "DELETE" })));
    for (const r of respostas) {
      if (!r.ok && r.status !== 404) throw new ErroHttp(502, `R2 respondeu ${r.status} ao apagar um arquivo.`);
      apagados++;
    }
  }
  return apagados;
}

async function copiar(de: string, para: string): Promise<void> {
  if (!(await existe(de))) throw new ErroHttp(404, "Arquivo de origem não está no R2.");
  const { aws, base } = r2();
  const r = await aws.fetch(`${base}/${codificar(para)}`, {
    method: "PUT",
    headers: { "x-amz-copy-source": `/${env("R2_BUCKET_ARQUIVOS")}/${codificar(de)}` },
  });
  if (!r.ok) throw new ErroHttp(502, `R2 respondeu ${r.status} ao copiar: ${(await r.text()).slice(0, 200)}`);
}

/** Status: secrets presentes e o bucket responde (lista 1 objeto); pega bucket com nome errado. */
async function status() {
  if (!r2Configurado()) return { r2: false, bucket: "faltam secrets" };
  const { aws, base } = r2();
  const u = new URL(base);
  u.searchParams.set("list-type", "2");
  u.searchParams.set("max-keys", "1");
  const r = await aws.fetch(u.toString());
  return { r2: true, bucket: r.ok ? "ok" : `R2 respondeu ${r.status}` };
}

function desfazerXml(s: string): string {
  return s
    .replace(/&#x([0-9a-fA-F]+);/g, (_, h) => String.fromCodePoint(parseInt(h, 16)))
    .replace(/&#(\d+);/g, (_, d) => String.fromCodePoint(Number(d)))
    .replace(/&lt;/g, "<").replace(/&gt;/g, ">").replace(/&quot;/g, '"').replace(/&apos;/g, "'").replace(/&amp;/g, "&");
}

/** Objetos com o prefixo: chave → tamanho em bytes (segue a paginação do ListObjectsV2). */
async function listar(prefixo: string): Promise<Map<string, number>> {
  const { aws, base } = r2();
  const objetos = new Map<string, number>();
  let token = "";
  do {
    const u = new URL(base);
    u.searchParams.set("list-type", "2");
    u.searchParams.set("prefix", prefixo);
    u.searchParams.set("max-keys", "1000");
    if (token) u.searchParams.set("continuation-token", token);
    const r = await aws.fetch(u.toString());
    const xml = await r.text();
    if (!r.ok) throw new ErroHttp(502, `R2 respondeu ${r.status} ao listar: ${xml.slice(0, 200)}`);
    for (const m of xml.matchAll(/<Contents>([\s\S]*?)<\/Contents>/g)) {
      const chave = /<Key>([\s\S]*?)<\/Key>/.exec(m[1])?.[1];
      const tamanho = Number(/<Size>(\d+)<\/Size>/.exec(m[1])?.[1] ?? 0);
      if (chave) objetos.set(desfazerXml(chave), tamanho);
    }
    token = /<IsTruncated>true<\/IsTruncated>/.test(xml)
      ? desfazerXml(/<NextContinuationToken>([\s\S]*?)<\/NextContinuationToken>/.exec(xml)?.[1] ?? "")
      : "";
  } while (token);
  return objetos;
}

// ------------------------------------------------------------------ Supabase (bucket antigo)

/** Arquivos do bucket antigo, com subpastas: caminho → tamanho em bytes. */
async function listarSupabase(sb: any, bucket: string, pasta = "", mapa = new Map<string, number>()): Promise<Map<string, number>> {
  for (let offset = 0; ; offset += 1000) {
    const { data, error } = await sb.storage.from(bucket).list(pasta, { limit: 1000, offset });
    if (error) throw new ErroHttp(502, `Supabase respondeu ao listar ${bucket}: ${error.message}`);
    const itens = data ?? [];
    for (const o of itens) {
      if (o.name === ".emptyFolderPlaceholder") continue;
      const caminho = pasta ? `${pasta}/${o.name}` : o.name;
      if (o.id) mapa.set(caminho, Number(o.metadata?.size ?? 0));
      else await listarSupabase(sb, bucket, caminho, mapa);
    }
    if (itens.length < 1000) return mapa;
  }
}

/** Objetos do módulo no R2, com o caminho relativo ao módulo: caminho → tamanho. */
async function listarModuloNoR2(modulo: string): Promise<Map<string, number>> {
  const noR2 = await listar(`${modulo}/`);
  return new Map([...noR2].map(([chave, tamanho]) => [chave.slice(modulo.length + 1), tamanho]));
}

/** Tempo máximo de uma chamada de `migrar` (a função tem limite de execução); o que faltar vai na próxima. */
const PRAZO_MIGRAR_MS = 100_000;

/** Copia um arquivo entre o bucket antigo e o R2, na direção pedida. */
async function copiarUm(sb: any, bucket: string, modulo: string, caminho: string, direcao: "para-r2" | "para-supabase") {
  const { aws, base } = r2();
  const url = `${base}/${codificar(`${modulo}/${caminho}`)}`;
  if (direcao === "para-r2") {
    const { data, error } = await sb.storage.from(bucket).download(caminho);
    if (error || !data) throw new Error(`Supabase não entregou o arquivo: ${error?.message ?? "arquivo vazio"}`);
    const r = await aws.fetch(url, { method: "PUT", body: data, headers: { "Content-Type": data.type || "application/octet-stream" } });
    if (!r.ok) throw new Error(`R2 respondeu ${r.status} ao gravar.`);
    return;
  }
  const r = await aws.fetch(url);
  if (!r.ok) throw new Error(`R2 respondeu ${r.status} ao ler.`);
  const blob = await r.blob();
  const { error } = await sb.storage.from(bucket).upload(caminho, blob, {
    contentType: r.headers.get("content-type") || "application/octet-stream",
    upsert: false,
  });
  if (error) throw new Error(`Supabase recusou o arquivo: ${error.message}`);
}

/**
 * Copia o que falta no destino, até `limite` arquivos copiados ou o prazo. Um arquivo com erro não trava os
 * outros: vai para `erros` e continua em `faltam` (será tentado de novo na próxima chamada).
 */
async function migrar(sb: any, modulo: string, direcao: "para-r2" | "para-supabase", limite: number) {
  const inicio = Date.now();
  const bucket = MODULOS[modulo];
  const noSupabase = await listarSupabase(sb, bucket);
  const noR2 = await listarModuloNoR2(modulo);
  const [origem, destino] = direcao === "para-r2" ? [noSupabase, noR2] : [noR2, noSupabase];
  const invalidos = [...origem.keys()].filter((c) => !chaveValida(`${modulo}/${c}`));
  const faltando = [...origem.keys()].filter((c) => !destino.has(c) && chaveValida(`${modulo}/${c}`));
  const erros: { caminho: string; motivo: string }[] = [];
  let copiados = 0;
  for (const caminho of faltando) {
    if (copiados >= limite || Date.now() - inicio > PRAZO_MIGRAR_MS) break;
    try {
      await copiarUm(sb, bucket, modulo, caminho, direcao);
      copiados++;
    } catch (e) {
      erros.push({ caminho, motivo: e instanceof Error ? e.message : String(e) });
    }
  }
  return {
    copiados,
    erros,
    existentes: origem.size - faltando.length - invalidos.length,
    faltam: faltando.length - copiados,
    total: origem.size,
    invalidos,
  };
}

async function conferir(sb: any, modulo: string) {
  const noSupabase = await listarSupabase(sb, MODULOS[modulo]);
  const noR2 = await listarModuloNoR2(modulo);
  const soNoSupabase = [...noSupabase.keys()].filter((c) => !noR2.has(c));
  const soNoR2 = [...noR2.keys()].filter((c) => !noSupabase.has(c));
  const tamanhoDiferente = [...noSupabase].filter(([c, t]) => noR2.has(c) && noR2.get(c) !== t).map(([c]) => c);
  const quantosIguais = [...noSupabase].filter(([c, t]) => noR2.get(c) === t).length;
  return { iguais: quantosIguais, soNoSupabase, soNoR2, tamanhoDiferente };
}
```

```ts
// Arquivos do sistema no Cloudflare R2, pela edge function `r2` (spec 2026-09-30-arquivos-r2-design.md).
// Transição de 30 dias (até 30/10/2026): envio só para o R2; leitura no R2 com reserva no bucket antigo do
// Supabase; apagar nos dois lados. Swipe file, Transcritor e Fireflies não usam este módulo.
import { supabase } from "@/integrations/supabase/client";
import { MODULOS_R2, chaveR2, urlImagemNota, type ModuloR2 } from "@/lib/r2Chaves";

const SUPABASE_URL = import.meta.env.VITE_SUPABASE_URL as string;
const CHAVE_PUBLICA = import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY as string;
const FUNCAO = `${SUPABASE_URL}/functions/v1/r2`;

/** O arquivo não está no R2 (a leitura e a cópia caem no Supabase). */
class NaoEstaNoR2 extends Error {}

async function chamar<T>(corpo: Record<string, unknown>): Promise<T> {
  const r = await fetch(FUNCAO, {
    method: "POST",
    headers: { apikey: CHAVE_PUBLICA, Authorization: `Bearer ${CHAVE_PUBLICA}`, "Content-Type": "application/json" },
    body: JSON.stringify(corpo),
  });
  const d = await r.json().catch(() => ({}));
  // 404 com { error } é a resposta da função para "não está no R2" (ler, copiar); outro 404 é a função fora do ar.
  if (r.status === 404 && typeof d.error === "string") throw new NaoEstaNoR2(d.error);
  if (!r.ok) throw new Error(d.error || `A função r2 respondeu ${r.status}`);
  return d as T;
}

/** Envia direto do navegador para o R2 (URL assinada de PUT), com progresso. Sobrescreve se já existir. */
export async function enviarR2(
  modulo: ModuloR2,
  caminho: string,
  corpo: Blob,
  tipo: string,
  onProgresso?: (fracao: number) => void,
): Promise<void> {
  const { url } = await chamar<{ url: string }>({ acao: "enviar", chave: chaveR2(modulo, caminho) });
  await new Promise<void>((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open("PUT", url);
    xhr.setRequestHeader("Content-Type", tipo || "application/octet-stream");
    xhr.upload.onprogress = (e) => {
      if (e.lengthComputable && e.total > 0) onProgresso?.(e.loaded / e.total);
    };
    xhr.onload = () => (xhr.status >= 200 && xhr.status < 300
      ? resolve()
      : reject(new Error(`Falha no envio do arquivo (HTTP ${xhr.status})`)));
    xhr.onerror = () => reject(new Error("Falha de rede ao enviar o arquivo"));
    xhr.send(corpo);
  });
}

/**
 * Baixa do R2. Se não conseguir (arquivo ainda não migrado, ou o R2 fora do ar), tenta o bucket antigo do
 * Supabase; se lá também não houver, devolve o erro mais útil.
 */
export async function baixarComReserva(modulo: ModuloR2, caminho: string): Promise<Blob> {
  try {
    const { url } = await chamar<{ url: string }>({ acao: "ler", chave: chaveR2(modulo, caminho) });
    const r = await fetch(url);
    if (!r.ok) throw new Error(`O R2 respondeu ${r.status} ao baixar o arquivo`);
    return await r.blob();
  } catch (erroR2) {
    // "Ainda não migrado" é esperado; qualquer outra falha do R2 ficaria escondida pela reserva até 30/10
    if (!(erroR2 instanceof NaoEstaNoR2)) console.warn("[r2] leitura caiu na reserva do Supabase:", erroR2);
    const { data, error } = await supabase.storage.from(MODULOS_R2[modulo]).download(caminho);
    if (data && !error) return data;
    throw erroR2 instanceof NaoEstaNoR2 ? (error ?? erroR2) : erroR2;
  }
}

/** Chave no R2, ou null quando o nome não vale como chave (arquivo antigo, que nunca foi para o R2). */
function chaveSeValida(modulo: ModuloR2, caminho: string): string | null {
  try {
    return chaveR2(modulo, caminho);
  } catch {
    return null;
  }
}

/** Apaga nos dois lados (R2 e bucket antigo), em lotes de 1.000. Arquivo ausente em um deles não é erro. */
export async function apagarNosDois(modulo: ModuloR2, caminhos: string[]): Promise<void> {
  for (let i = 0; i < caminhos.length; i += 1000) {
    const lote = caminhos.slice(i, i + 1000);
    const chaves = lote.map((c) => chaveSeValida(modulo, c)).filter((c): c is string => c !== null);
    if (chaves.length) await chamar({ acao: "apagar", chaves });
    const { error } = await supabase.storage.from(MODULOS_R2[modulo]).remove(lote);
    if (error) throw error;
  }
}

/** Copia dentro do R2; se a origem só existir no Supabase, baixa de lá e envia ao R2. */
export async function copiarComReserva(modulo: ModuloR2, de: string, para: string, tipo: string): Promise<void> {
  try {
    await chamar({ acao: "copiar", de: chaveR2(modulo, de), para: chaveR2(modulo, para) });
  } catch (e) {
    if (!(e instanceof NaoEstaNoR2)) throw e;
    const blob = await baixarComReserva(modulo, de);
    await enviarR2(modulo, para, blob, tipo);
  }
}

/** Arquivos de uma pasta do módulo nos dois lados, sem repetir (caminhos relativos ao módulo). */
export async function listarNosDois(modulo: ModuloR2, pasta: string): Promise<string[]> {
  const pastaLimpa = pasta.replace(/\/+$/, "");
  const { chaves } = await chamar<{ chaves: string[] }>({ acao: "listar", prefixo: `${chaveR2(modulo, pastaLimpa)}/` });
  const noR2 = chaves.map((k) => k.slice(modulo.length + 1));
  const { data } = await supabase.storage.from(MODULOS_R2[modulo]).list(pastaLimpa, { limit: 1000 });
  const noSupabase = (data || []).filter((o) => o.id).map((o) => `${pastaLimpa}/${o.name}`);
  return [...new Set([...noR2, ...noSupabase])];
}

/** Endereço fixo de uma imagem de nota (vai dentro do documento da nota). */
export function urlDaImagemNota(arquivo: string): string {
  return urlImagemNota(SUPABASE_URL, arquivo);
}
```

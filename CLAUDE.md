## Backlog (GitHub Issues)
Backlog = GitHub Issues deste repo, via `gh`.
- Ao iniciar a sessão: rode `gh issue list` e resuma o que está aberto antes de propor trabalho.
- Trabalho que não cabe no turno, bug achado de passagem ou ideia adiada vira issue (`gh issue create`, com título curto, corpo com contexto e critério de aceite, e rótulo).
- Ao começar uma issue, comente nela. Ao terminar, commit/PR com "Closes #n".
- Antes de encerrar: `gh issue comment n` com o que foi feito, o que falta e onde parou.
- Antes de criar uma issue, procure duplicada com `gh issue list --search`.
- Nunca feche issue sem entrega verificada.
